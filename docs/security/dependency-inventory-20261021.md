## Consumer evidence and limits

- `vite.config.ts` imports Vite, vinext and the Cloudflare plugin; `eslint.config.mjs` imports the lint preset; the `db:generate` script invokes Drizzle Kit. These establish build/config/CLI consumers, not whether a vulnerable function can be reached from a public request.
- `npm explain` showed that `sharp` 0.34.5 is Miniflare’s dev dependency. Next’s separate optional `sharp` is 0.35.5 and did not appear as an affected audit node. `image-size` is imported from vinext’s `metadata-route-build-data.js`; the prior checkpoint’s emitted Worker inspection found no `image-size` or `sharp` reference. This inventory did not rebuild or re-inspect deployment output, so that finding remains bounded to the prior checkpoint.
- The app imports MapLibre directly and `app/lib/discovery-index.ts` inflates the compressed discovery index with the platform `DecompressionStream`. No app-source import of `fflate`, `fast-uri`, `js-yaml`, `undici`, or `sharp` was found. That narrows consumer paths but does not prove those dependencies are absent from all generated bundles.
- Production-marked `baseline-browser-mapping` and `source-map-js` flow through Next/PostCSS dependency paths. A lockfile production flag is not proof of inclusion in an executable Worker/browser bundle. Keep both as unknown until the generated Worker and browser chunks are inspected against the exact release build.
- The moderate esbuild findings and high Vite, Wrangler, Miniflare, undici and WebSocket findings are associated with the build/local simulation stack. Do not expose a development server or process untrusted build inputs; this observation is not a substitute for patching the dependencies.

## First leaf patch candidate

First leaf candidate for a separately reviewed patch: update `fflate` from locked 0.7.4 to 0.7.5. The audit marks 0.7.0–0.7.4 affected and reports a compatible fix available. The lock path is `vinext` → `@vercel/og` → `satori` → `@shuding/opentype.js` → `fflate`; both the lock and current npm metadata for `@shuding/opentype.js@1.4.0-beta.0` specify `fflate: ^0.7.3`, which admits 0.7.5. This establishes a parent-range-compatible candidate only; the lock was not changed, and a fresh audit/build must verify the patch. Other leaf candidates remain backlog and have no proposed versions selected here. Do not force overrides or change framework roots without primary review.

Review the Cloudflare plugin/Wrangler/Miniflare family, vinext and its Vite plugins, lint preset, and Drizzle Kit chain as separate follow-up batches. These affect direct tool versions or framework build output; validate with a fresh audit and relevant build checks before selecting versions. No version is declared safe here without that verification.

Before beta expansion or public launch, repeat the audit on the release lock and inspect the exact built Worker and browser assets; this report does not establish runtime exploitability or final release safety.
